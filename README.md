# Library

**Apps, without the mall.**

Library is a private-first Android app store for software shipped from GitHub Releases. It is built for a personal or small-team catalog where some repositories are public, some are private, source may or may not be exposed, and every install should have a clear provenance trail.

This repository contains the Android client, the catalog generator, GitHub release discovery, and the CI pipelines that publish both Library itself and the rolling app catalog.
